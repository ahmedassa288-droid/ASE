BASIC ENGLISH • MASTER LEARNING ZONE

📘 شرح + فهم + تدريب + حفظ الكلمات

قسم تعليمي جديد مبني على موضوعات وأسئلة الاختبارات الستة. كل قاعدة معها شرح مبسط، أمثلة، أخطاء شائعة، مفتاح للحفظ، ثم «اختبر نفسك». ويوجد قاموس كلمات كامل مع اختبار حفظ كلمات مستقل.

طريقة المذاكرة: اقرأ القاعدة → شاهد المثال → راجع الخطأ → حل «اختبر نفسك». لا تنتقل بسرعة لمجرد معرفة الإجابة؛ افهم لماذا.

⏱ الأزمنة

  • every day / usually / often → Present Simple
  • now / at the moment → Present Continuous
  • yesterday / last / ago / in 1492 → Past Simple
  • was/were + ing → Past Continuous

❗ بعد DID / DOES

Did + subject + base verb? Does + subject + base verb? didn't + base verb
✅ Did you go?
✅ Where does he live?

🔢 Quantity

  • a little → uncountable
  • a few → countable plural
  • some → شائع في العروض/الإثبات
